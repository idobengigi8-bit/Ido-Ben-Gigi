# כפר יונה נוער — מעקב הגעה

אפליקציית web חד-קובצית (`app.html`) למעקב הגעה של שחקני קבוצת הנוער — מי הגיע, מי איחר, מי נעדר, ואחוזי נוכחות לאורך העונה.

## הפעלה ראשונה

1. הרץ פעם אחת את `schema.sql` ב-Supabase שלך (Project → SQL Editor → הדבק את התוכן → Run). זה יוצר את הטבלאות `players`, `sessions`, `attendance`.
2. פתח את `app.html` בדפדפן (או פרסם עם GitHub Pages).
3. קוד כניסה: `0406` (ניתן לשנות בקובץ — חפש `const PIN`).

## שימוש

- **שחקנים** — הוספת/עריכת שחקנים ברשימת הקבוצה.
- **אימונים** — יצירת אימון חדש (תאריך + הערה), ולחיצה עליו פותחת סימון נוכחות מהיר (נוכח / איחור / נעדר) לכל שחקן.
- **דוח נוכחות** — טבלת אחוזי הגעה לכל שחקן לאורך העונה, עם ייצוא ל-CSV.
- **דשבורד** — תמונת מצב כללית ואימונים אחרונים.

## בהמשך

תוכן אימונים ותכנון תרגילים אפשר להוסיף כטאב נוסף באותה אפליקציה, מחובר לאותו Supabase.
